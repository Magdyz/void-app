**Last Updated:** 2026-01-05

## 🎯 v1.0 in One Sentence

**Generic notifications that reveal zero metadata to Google, OS, or observers through identical FCM payloads, constant 4KB responses, and Poisson heartbeat mixing.**

---

## 🔑 Key Files

### Client-Side (Android)
```
app/src/play/kotlin/com/void/app/service/VoidFirebaseService.kt
  → Receives FCM wake signals (heartbeat or message - indistinguishable)
  → Always triggers MessageSyncWorker

blocks/messaging/src/main/kotlin/com/void/block/messaging/sync/MessageSyncEngine.kt
  → Fetches mailbox (constant 4KB response)
  → Posts generic notification "VOID - Activity Detected"
  → Debouncing (60 seconds)
  → v1.1 Hostile Mode code COMMENTED OUT

app/src/main/kotlin/com/void/app/MainActivity.kt
  → Clears notification on onCreate/onResume/onNewIntent

slate/network/src/main/kotlin/com/void/slate/network/supabase/FetchMailboxClient.kt
  → Fetches 4KB mailbox via Edge Function
  → Parses magic byte (0x01 = messages, 0x00 = noise)
```

### Server-Side (Supabase)
```
supabase/functions/heartbeat-sender/index.ts
  → Sends IDENTICAL FCM payloads (heartbeat = message)
  → Poisson distribution (λ = 15 minutes)
  → Triggered by pg_cron every 1 minute

supabase/functions/fetch-mailbox/index.ts
  → ALWAYS returns exactly 4KB
  → Magic byte + JSON + random padding (or pure noise)
  → Validates ephemeral tokens
```

### Google/FCM Cannot See:
❌ Which pushes contain real messages
❌ Message counts
❌ Message timing
❌ Who is messaging whom

### Network Observers Cannot See:
❌ Whether 4KB response contains real data
❌ Communication patterns (hidden in heartbeats)

### Android OS Cannot See:
❌ Sender names
❌ Message counts
❌ Content previews

## 📱 Notification Behavior

### New Message (Device Locked)
```
FCM wake → Fetch 4KB → Decrypt → Show "Activity Detected" → User opens app → See real messages
```

### Heartbeat (No Messages)
```
FCM wake → Fetch 4KB noise → Decrypt → No notification → User unaware
```

### Active Conversation
```
5 messages in 30 seconds → ONLY 1 notification (60s debounce)
```

## 🎯 Critical Security Requirements

### 1. FCM Payload Uniformity
**Requirement:** Heartbeat FCM = Message FCM (byte-for-byte identical)
**Location:** `heartbeat-sender/index.ts` lines 188-212
**Test:** Compare FCM payloads with network monitor

### 2. Constant Response Size
**Requirement:** Mailbox fetch ALWAYS returns 4096 bytes
**Location:** `fetch-mailbox/index.ts` lines 41, 150-231
**Test:** Network monitor showing all responses are 4KB

### 3. Generic Notification
**Requirement:** "VOID - Activity Detected" (no variables)
**Location:** `MessageSyncEngine.kt` lines 294-301
**Test:** Android notification logs

### 4. Single Notification ID
**Requirement:** NOTIFICATION_ID_ACTIVITY = 10000 (constant)
**Location:** `MessageSyncEngine.kt` line 51
**Test:** Multiple messages → single notification

### 5. Debounce Enforcement
**Requirement:** 60 seconds minimum between notifications
**Location:** `MessageSyncEngine.kt` lines 281-287
**Test:** Send 5 messages in 30 seconds → 1 notification

## 🔧 Quick Debugging

### Check FCM Payload
```bash
# Logcat filter
adb logcat -s VoidFirebaseService

# Look for:
"⚡ v1.0 Poisson Ghost Protocol - Wake signal received"
"Classification: UNKNOWN (heartbeat OR message - indistinguishable)"
```

### Check Mailbox Fetch
```bash
# Logcat filter
adb logcat -s FetchMailboxClient

# Look for:
"✓ Real messages detected (magic byte: 0x01)"  # Real message
"○ Noise response (magic byte: 0x00)"          # Heartbeat
```

### Check Notification
```bash
# Logcat filter
adb logcat -s MessageSyncEngine

# Look for:
"📬 Activity notification posted (debounced)"        # Notification shown
"⏭️  Notification suppressed (debounced - Xs since last)"  # Debounced
"🔕 Activity notification cleared"                   # User opened app
```

### Check Heartbeat Timing
```sql
-- Supabase SQL Editor
SELECT
  mailbox_hash,
  next_heartbeat_at,
  heartbeat_interval_seconds / 60.0 AS interval_minutes,
  EXTRACT(EPOCH FROM (next_heartbeat_at - NOW())) / 60.0 AS minutes_until_next
FROM ephemeral_tokens
WHERE fcm_token IS NOT NULL
ORDER BY next_heartbeat_at ASC;
```
